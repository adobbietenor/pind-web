## Gotchas met in M3.3

- **Bash heredocs fail here** (a `cat` waiting on stdin hangs the tool; a heredoc holding
  apostrophes breaks the shell's quoting). Write files with the Write tool; for scripted
  edits, write the Python script to the scratchpad with Write and run it.
- **The Supabase CLI's statement splitter** broke on `if v <> case … end then`: assign
  the `case` to a variable first.
- **A new enum value needs its own migration** — it can't be used in the transaction
  that adds it.
- **A switch column must be named after its kind:** `admin_switch_off` writes the column
  the kind names.
- **The harness sweep** must delete A16's ticks before crews (`on delete restrict`).
